# Streamflix Dreams

Create a full-stack video streaming app called Streamflix. It needs a Netflix-style dark UI, a hero banner with a 'Play' button, rows of movie posters (use TMDB API for data), a user 'My List' feature, and a video player that supports HLS streaming.
